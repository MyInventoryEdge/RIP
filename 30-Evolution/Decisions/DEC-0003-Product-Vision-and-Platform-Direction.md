# DEC-0003 — Product Vision and Platform Direction

**Decision ID:** DEC-0003  
**Proposal:** RIP-PROP-0003  
**Status:** Approved  
**Decision Date:** 2026-07-28  
**Authority:** Bob Berry, RIP Gatekeeper  

## Decision

RIP SHALL be governed and developed as a governed organizational knowledge platform.

The Organization SHALL be the primary object.

Knowledge, Governance, and Execution SHALL be treated as foundational pillars.

The repository SHALL preserve the approved lifecycle through which conversation-derived understanding becomes institutional knowledge.

RIP SHALL model concepts independently from providers, preserve knowledge provenance, distinguish supplied and inferred knowledge, represent Changes as traceable events, generate Operations from organizational understanding, and apply its own governance discipline to itself.

## Rationale

The organization reached a coherent understanding that materially exceeds the repository's previous description.

Preserving that understanding only in conversation would contradict RIP's mission.

Because these decisions are cross-cutting and already approved, repository alignment should occur as one consistency pass rather than through artificial phases.

## Alternatives Rejected

- Leave the existing repository unchanged until executable implementation.
- Document only part of the approved model.
- Stage the documentation into multiple work packages.
- Delegate organization of already-approved knowledge to an external engineer or AI.

## Affected Artifacts

- Vision
- README
- Constitution
- Lexicon
- Conceptual Model
- Governance
- Organizational Learning
- Proposal Template
- Proposal Lifecycle
- Evolution Register
- Hosts guidance
- Repository onboarding

## Implementation Requirement

Update all affected foundational artifacts so the repository communicates one coherent model.

## Validation Requirement

Conduct an internal consistency review and then request an independent repository assessment without providing the originating conversation.

## Reconsideration Criteria

Reopen this decision if validated implementation or real organizational onboarding demonstrates a foundational contradiction in the approved model.
