# ADR-0005 — Quarantine governs ambiguous publication state
**Status:** Accepted

**Question:** How is ambiguous publication evidence handled?
**Context:** Journal Authority cannot infer whether an orphan is legitimate interruption or attack.
**Alternatives Considered:** Heuristic repair; deletion; governed disposition.
**Evidence:** JA-2C constitutional revision.
**Decision:** Signed dispositions preserve, quarantine, retire, abandon, or supersede ambiguous evidence.
**Constitutional Justification:** Disposition cannot create commitment or rewrite history.
**Consequences:** Publication blocks until authorized disposition where required.
**Authorities Affected:** Journal Authority.
**Related Constitutional Evidence:** JA-2C.
**Superseded By:** —
