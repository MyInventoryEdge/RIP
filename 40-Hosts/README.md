# Hosts

Hosts are constitutional executors.

They provide operational interfaces between governed organizational knowledge and engineering or organizational work.

A Host may:

- retrieve governed knowledge;
- inspect evidence;
- infer technical knowledge within declared boundaries;
- identify missing context or authority;
- generate ideas and proposals;
- explain organizational relationships;
- execute approved workflows;
- validate implementation;
- generate operational views.

A Host may not:

- silently create organizational authority;
- treat inference as approval;
- conceal uncertainty;
- bypass governance;
- overwrite history;
- redefine organizational concepts through provider assumptions.

This directory will contain:

- Host contracts;
- capability boundaries;
- conformance requirements;
- reference Host implementations;
- validation suites.

Developer Studio is expected to become a reference Host implementation, but conformance must be governed and validated rather than assumed.
